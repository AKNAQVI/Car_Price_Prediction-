# Car Price Prediction

A simple machine learning project to predict car prices.  
Users can enter car details, and the app predicts the price along with car value, history, mileage, and other relevant information.

## 📌 Features
- Predicts car price based on user input  
- Shows car mileage, history, and estimated value  
- Interactive UI using Streamlit
